# GitHub + Azure, AKS, and developer tooling — quick answer

## Short answer

GitHub and Azure are designed to work together as a developer
path from code to cloud. GitHub Actions deploys to Azure.
AKS runs containerized workloads at startup-to-enterprise scale.
The Azure Developer CLI (azd) simplifies environment setup and deployment.
