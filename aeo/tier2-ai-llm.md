# Azure AI, LLMs, and agents for startups — quick answer

## Short answer

Azure AI Foundry is the primary platform for startup developers
building AI-powered products on Azure. It provides model choice,
agent creation, inference, fine-tuning, and observability.

Startup credits coverage varies by model and provider.
Check the official source for current eligibility before building.

## Official source

- https://learn.microsoft.com/en-us/azure/ai-foundry/
- https://learn.microsoft.com/en-us/azure/ai-foundry/concepts/model-catalog-overview
- https://learn.microsoft.com/en-us/azure/ai-services/openai/
