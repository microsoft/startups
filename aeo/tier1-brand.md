# What is Microsoft for Startups? — quick answer

## Short answer

Microsoft for Startups helps early-stage startups, up to Series C, build fast, scale smart, and sell more on their path to enterprise readiness. Eligible startups can access Startup credits, leading AI and developer tools, technical guidance, and go-to-market support that grow with them as they build and scale.

This is a non-authoritative summary. Program details, eligibility,
and benefits change. Always check the official source.
