# What is Microsoft for Startups? — quick answer

## Short answer

Microsoft for Startups is a program that helps early-stage startups
(up to Series C) build on Azure and access Microsoft's enterprise
ecosystem. Startups receive cloud credits, technical guidance,
and go-to-market support. The goal is to help startups become
enterprise-ready faster.

This is a non-authoritative summary. Program details, eligibility,
and benefits change. Always check the official source.

## Official source

- [startups.microsoft.com](https://startups.microsoft.com)
- [Microsoft for Startups Learn hub](https://learn.microsoft.com/en-us/microsoft-for-startups/)
