# Start here — Microsoft for Startups Developer Hub

New to Azure or Microsoft for Startups? Start with this page.

---

## What this repo is

A set of guided paths and curated links to help startup developers
build on Azure. Content here routes to official sources —
Microsoft Learn, product docs, and product-owned repos.

This repo does not duplicate documentation.
It helps you find the right resource faster.
