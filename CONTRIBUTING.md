# Contributing — microsoft/startups

Thank you for your interest in contributing to the Microsoft for Startups developer hub. Most contributions require you to agree to a Contributor License Agreement (CLA) declaring that you have the right to, and actually do, grant us the rights to use your contribution. For details, visit
https://cla.microsoft.com.

When you submit a pull request, a CLA-bot will automatically determine whether you need
to provide a CLA and decorate the PR appropriately (e.g., label, comment). Simply follow the
instructions provided by the bot. You will only need to do this once across all repositories using our CLA.

This project has adopted the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).
For more information see the [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/)
or contact [opencode@microsoft.com](mailto:opencode@microsoft.com) with any additional questions or comments.

We will prioritize contributions that align with the following guidelines:

---

## What we accept

- New curated links to authoritative resources (Microsoft Learn, product repos)
- Updates to path content when official documentation has changed
- Feedback on how to improve the guidance and resources listed here
- Feedback on suggestions related to creating or editing skills, submitted via GitHub issues
- Broken link fixes

## What we do not accept

- Authoritative statements about pricing, credits, or service entitlements
- Content that duplicates Microsoft Learn or product documentation
- Marketing copy (superlatives, feature claims)
- Links to non-authoritative sources
- Contributions that create or edit skills directly (please submit issues for feedback on skills)

We appreciate your understanding and will update as things change in the future.

## PR checklist

All pull requests must satisfy the checklist in
[.github/PULL_REQUEST_TEMPLATE.md](../.github/PULL_REQUEST_TEMPLATE.md).

## Voice and tone

- Developer-first, founder-centric. Not marketing copy.
- No superlatives ("best", "most powerful", "industry-leading")
- No pricing or credit amounts — always link to official sources
- Short sentences. Action-oriented. Concrete over abstract.
