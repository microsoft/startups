# Workshops — Partner and contributor drop zone

This folder is for workshop materials, partner content drops,
and event-specific technical assets contributed by Microsoft
for Startups team members, Startup Advisors, and partners.

---

## How to contribute a workshop drop

1. Create a folder named `YYYY-MM-topic/` (example: `2026-05-build/`)
2. Add the following files:

| File | What it contains |
|---|---|
| `README.md` | Workshop title, audience, goals, agenda overview |
| `links.md` | Canonical resource links used in the workshop |
| `owners.md` | Contributor name, org, and update cadence |

3. Open a pull request using the
   ./../.github/ISSUE_TEMPLATE/link_request.yml

---

## Content rules

- No pricing or credit amounts — link to official sources
- No proprietary or internal-only content
- All technical claims must link to an authoritative source
  (Microsoft Learn or a product-owned repo)
- Folder name must follow `YYYY-MM-topic/` convention
