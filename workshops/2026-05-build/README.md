# Workshop — Microsoft Build 2026 · AI Agents for the Enterprise

**Contributor:** Bhaskar Lokanathan, Microsoft for Startups
**Event:** Microsoft Build 2026 · June 2–3 · San Francisco
**Audience:** Startup developers building AI agents for enterprise use cases

---

## Workshop goals

By the end of this workshop, participants will be able to:

- Understand the Azure AI Foundry agent model
- Build a basic agent with tool use
- Design an agent architecture that passes enterprise security review
- Know how to list an agent-powered product on Azure Marketplace
