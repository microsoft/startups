# Guided paths

Choose a path based on what you are building or the next problem you
need to solve. Each path organizes official documentation and maintained
repositories for startup developers building on Azure.

## Choose your path

| Path | Start here if you want to |
|---|---|
| [00 - Start here](./00-start-here/) | Get oriented on Azure and find Microsoft for Startups onboarding resources |
| [01 - Build fast](./01-build-fast/) | Build your first workload with application hosting, data services, and CI/CD |
| [02 - Scale smart](./02-scale-smart/) | Plan for multi-tenancy, identity, observability, and resilience |
| [03 - Sell more](./03-sell-more/) | Explore Microsoft Marketplace, co-sell resources, and enterprise buyer expectations |
| [04 - AI agents](./04-ai-agents/) | Explore models, agent development, and tool integration with Microsoft Foundry |
| [05 - Enterprise readiness](./05-enterprise-readiness/) | Prepare for security and compliance assessments with identity, secrets management, and audit logging |

## How to use these paths

1. If you are new to Azure or Microsoft for Startups, begin with
   [Start here](./00-start-here/). Otherwise, choose the path that fits
   your current goal.
2. Follow the recommended order within that path. You do not need to
   complete every path before moving forward.
3. Use the canonical resources linked from each path for product details.
   Check its ownership page for maintainers and review dates.
4. Return to this index when you are ready to tackle another goal.
