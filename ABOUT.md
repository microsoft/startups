# About this repo

**Repository:** [github.com/microsoft/startups](https://github.com/microsoft/startups)
**Maintained by:** Microsoft for Startups Developer Marketing
**Publishing cadence:** Monthly featured drops + ongoing index updates

---

## What this repo does

This repo is a developer-native front door for startup developers
building on Azure. It provides:

- **Guided paths** organized by what you are trying to accomplish
- **Canonical link indexes** pointing to authoritative sources
- **Vertical-specific pages** for regulated and specialized industries
- **AEO prompt routing pages** for common founder questions
- **Monthly featured drops** from the Microsoft for Startups team
  and partner contributors

---

## What this repo does not do

This repo does not own technical truth.

- It does not duplicate Microsoft Learn content
- It does not provide authoritative guidance on pricing,
  credits, or service entitlements
- It does not replace product documentation

Every path links to the source that owns the content.

---

## How content stays accurate

Each path folder includes an `owners.md` file that records:
- Technical owner (the team or person who validates accuracy)
- Content owner (the person who maintains the Markdown)
- Update cadence (how often the content is reviewed)

Pull requests that add technical claims must include a link
to an authoritative source (Microsoft Learn or a product-owned repo).
See [governance/CONTRIBUTING.md](./governance/CONTRIBUTING.md).
