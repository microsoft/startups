# Microsoft for Startups

![Microsoft for Startups](./images/mfs.png)

A developer-first collection of guided paths, curated link indexes,
and prompt routing pages to help startup developers build, scale,
and ship on Azure.

This repo is a router, not a source of truth.
For pricing, credits, and service entitlements, always follow the
official sources linked below.

[Start here](./START_HERE.md)

| Path | Who it's for |
